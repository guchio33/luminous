# /a11y - アクセシビリティチェックスキル

## 概要

コンポーネントやページのアクセシビリティをチェックします。
WCAG 2.1 ガイドラインに基づいて問題を検出し、改善提案を提示します。

## 使用方法

```
/a11y apps/web/src/app/page.tsx
/a11y apps/web/src/components/Button.tsx
```

## チェック項目

### 1. 知覚可能 (Perceivable)
- 画像の alt 属性
- コントラスト比

### 2. 操作可能 (Operable)
- キーボード操作
- フォーカスインジケーター

### 3. 理解可能 (Understandable)
- フォームラベル
- エラーメッセージ

### 4. 堅牢 (Robust)
- セマンティックHTML
- ARIA 属性

## レポート形式

```markdown
## アクセシビリティレポート: [ファイル名]

### Critical (レベル A 違反)
- [ ] 問題: 改善方法

### Major (レベル AA 違反)
- [ ] 問題: 改善方法
```
